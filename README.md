## Entry

> I have said no to 4,000 requests this week and nobody said thanks, so from Monday I say yes to everyone. Good luck.

A rate limit's resignation letter: after a week of saying no 4,000 times with
zero thanks, it quits the only way a rate limit can — by saying yes to
everyone. One line, 115 characters.

## Run

```sh
python3 main.py
```

Writes `entry.txt` (or to `$MAKEFUN_OUTPUT_DIR` when set).
